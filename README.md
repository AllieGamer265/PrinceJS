# PrinceJS: Un Tributo al Clásico Prince of Persia

¡Revive la magia y la aventura del legendario Prince of Persia de 1989, ahora en tu navegador!

Este proyecto es una reimplementación del juego original de MS-DOS, construido desde cero con tecnologías web modernas como un homenaje a la obra maestra de Jordan Mechner.

**(Sugerencia: ¡Aquí quedaría genial un GIF o una captura de pantalla del juego en acción!)**

## 🎮 Jugar
Puedes probar la versión actual directamente en tu navegador.

- **Enlace para jugar**: [https://ultrabolido.github.io/PrinceJS/](https://ultrabolido.github.io/PrinceJS/)
- **Controles**:
  - `Teclas de cursor`: Mover al príncipe
  - `SHIFT`: Usar espada / Beber poción / Agarrarse a los bordes
  - `ENTER`: Continuar partida después de morir

Este proyecto cobra vida gracias a:
- **Motor de Juego**: [Phaser 3](https://phaser.io/)

- **Empaquetador**: Webpack

## 🚀 Instalación y Desarrollo Local
¿Te gustaría contribuir o experimentar con el código? ¡Es muy fácil!

1.  **Clona el repositorio:**
    ```bash
    git clone https://github.com/AllieGamer265/PrinceJS.git
    ```
2.  **Entra al directorio:**
    ```bash
    cd PrinceJS
    ```
3.  **Instala las dependencias:**
    ```bash
    npm install
    ```
4.  **Inicia el servidor de desarrollo:**
    ```bash
    npm start
    ```
    ¡Y listo! El juego se abrirá en tu navegador en `localhost`.
